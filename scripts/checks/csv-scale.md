# CSV toolkit — what has actually been tested

The pages claim "1GB+" only because a file over 1 GB was opened and operated on in a real browser.
Re-run this before changing `TESTED_GB` / `TESTED_LABEL` in
`src/components/tools/flagship/csv/pages.js`.

**Environment:** Chrome (headless, Windows 11), production build (`npm run build`), file chosen through the
page's own file input. Files generated by a small Node script (7 columns, quoted fields, an embedded
newline in every 50th row).

| File | Rows | Operation | Time | Result |
|---|---|---|---|---|
| 1.05 GB | 10,540,000 | Index (open) | 21 s | 10,540,000 rows, header and types detected |
| 1.05 GB | 10,540,000 | Jump to the last rows / row 5,000,000 | < 2 s | Correct rows shown (scaled scrollbar) |
| 1.05 GB | 10,540,000 | Remove duplicates | 47 s | 0 removed (file has none) — correct |
| 251 MB | 2,560,000 | Remove duplicates | 11 s | 255,999 removed — matches the number of injected duplicates |
| 251 MB | 2,560,000 | Filter (country = Pakistan) | 23 s | 256,001 rows — matches an independent line count |
| 251 MB | 2,560,000 | Sort (external merge, 7 runs) | 64 s | Completed; result re-opened in the viewer |
| 25 MB (filtered) | 256,001 | Split into 100,000-row parts | 1 s | 3 files in a zip |
| 25 MB (filtered) | 256,001 | Convert to .xlsx | 18 s | 1 sheet, 256,001 rows |

Browser memory (all Chrome processes): about 2.2 GB after indexing the 1.05 GB file, about 4.7 GB after the
duplicate removal (the result Blob and the hash set are held in memory). Plan for that on a machine with
8 GB or less. The offset index costs 8 bytes per row, so roughly a hundred million rows is the practical ceiling.

**Not tested:** Safari and Firefox, mobile browsers, files above 1.05 GB, more than ~10.5 million rows,
UTF-16 files (rejected with a message), non-UTF-8 single-byte encodings (displayed as UTF-8).

Unit-level correctness (quoted newlines across block boundaries, BOM, CRLF, ragged rows, semicolons, merge,
split, dedupe, sort, xlsx read back with ExcelJS): `node scripts/checks/csv.mjs`.
